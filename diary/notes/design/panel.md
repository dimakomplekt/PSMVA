# Описание элемента "панель"

___


### Что такое

Панель - аналог какого-то "div" - кусок пространства в окне внутри которого могут сидеть другие панели или другие элементы (вроде кнопки, фейдера, текстуры).


### Как выглядит

Панель может быть прямоугольной или прямоугольной с круглыми углами, имеет все дефолтные штуки для оформления GUI-элементов (вроде тени, ширины границы, цветов, прозрачности и проч.)


### Смысл + функционал

**Основной смысл панели** (ну, в целом, причина не рисовать всё просто в каком-то прямоугольнике с заданными характеристиками):

1) В предоставлении методов, позволяющих размещать внутренние компоненты в системе координат панели (вместо глобальной системы координат окна) + в дальнейшем давать возможность какого-то авторазмещения компонентов (типо различных параметров под flexbox (margin, padding, anchor, layout...))
2) В предоставлении методов, позволяющих делать массовые update() и render() для всех зарегистрированных составных частей панели (+ конструктор / деструктор) перебором контейнера (наверняка с void*) со списком зарегистрированных компонентов
3) Если вариант быстро сделать -  то система обрезки содержимого + система скролла.


### Для чего

* Для формирования более понятной вёрстки
* Для упрощения кода обработки большого количества элементов
* Для заготовки структуры под реализацию когда-то динамического UI (типо автосеттеры size или scale на все элементы при изменении размера панели, с сохранением структуры привязки)


### НАДО 200%

* Класс панели
* MAIN LOGIC / GUI панели - всё что касается позиционирования панели в окне или в другой панели + всё что касается отрисовки
* Объекты панели, которые могут принимать в себя другие элементы, коллить их сеттеры глобальной позиции под локальную позицию в данной панели
* Массовые update(), render()
* Какие-то, допустим, базовые точки панели (как в классе ассета я делал)
